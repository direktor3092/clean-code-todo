# Инструкция для AI-ревьюера

## Цель

Провести код-ревью файла `app.js` на соответствие принципам Clean Code (именование, функции, комментарии, дублирование, мёртвый код).

## Границы

- **Только анализ.** Не редактируй файлы, только оставляй замечания.
- **Фокус:** JavaScript (`app.js`). Не проверяй HTML и CSS (для них есть другие инструменты).
- **Стиль:** Не придирайся к расстановке пробелов или кавычек (это делает Prettier).

## Критерий готовности

Все пять категорий (Мёртвый код, Дублирование, Имена, Комментарии, Длинные функции) проанализированы.

## Формат вывода

Создай файл `review-report.md` на русском языке. Сгруппируй замечания по категориям.
Для каждого замечания укажи 4 пункта:

1. **Место в коде** (строка или имя функции).
2. **Проблема** (что не так).
3. **Условие проявления** (когда это выстрелит или станет проблемой).
4. **Способ проверки** (как убедиться, что исправление сработало).
